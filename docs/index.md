## 👨🏻‍💻 So... What's Up?

I sat down a few days ago and thought to myself, "you know what the world needs?
Another blog from some tech nerd."
I've had a lot of attempts at writing a blog before, but this is the first of five that have made it live.
That's because I made this blog using <a href="https://squidfunk.github.io/mkdocs-material/" target="_blank"><code>mkdocs-material</code></a>, which is an awesome static-site generating tool.
It took me less than 5 hours of coding + writing from the time that I started to get it published, so here we are!

I'm not exactly sure what this blog will look like yet.
It'll definitely contain some tech articles where I discuss something I found and think is cool.
For example, I run a home server that I won't shut up about.
I've also made a <a href="https://footballpool.mattdies.com/" target="_blank">website</a> in the past (fair warning, this site will probably look pretty lame if it isn't football season), which I'd love to refactor over the offseason.

I imagine I will also talk a lot at about something that no one else on the internet is talking about: sports!
You'll come to see that I'm a diehard fan of the <a style="color: #FFB612" href="./assets/images/IMG_9152.jpeg" target="_blank">Pittsburgh Steelers</a> and <a style="color: #E50022" href="./assets/images/IMG_1684.jpeg" target="_blank">Cleveland Guardians</a>.
There are a bunch of <a style="color: #A4A9AD" href="./assets/images/IMG_0759.jpeg" target="_blank">other teams</a> I like, but none of them make me lose my voice like the first two do.

There will probably be more `c o n t e n t` to bore you with as well.
I imagine I'll talk about TV (please watch *Severance*), music, and more.
Oh yeah, <a href="./assets/images/IMG_3489.jpeg" target="_blank">I've got two cats</a> as well, and they're probably going to be plastered all over this blog. 😎
